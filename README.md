**Student Name:** Prateek Mani Tripathi  
**Project:** Python Console-Based Game

## 📌 About
Lost Island is a simple treasure-hunt game where the player explores different locations, searches for clues, and tries to find the hidden treasure.

## 🎯 Objective
The main objective is to reach the Cave by following the clues and finally find the treasure.

## ✨ Features
- Player name input
- Menu and instructions
- Explore different locations
- Search and collect clues
- Random events during movement
- Treasure finding system
- Invalid input handling

## 🐍 Python Concepts Used
- **List:** Stores locations
- **Tuple:** Stores available choices
- **Set:** Stores collected clues
- **Dictionary:** Stores room and clue information
- **Functions:** Organizes different parts of the game
- **Loops:** Keeps the game running
- **If-Else:** Handles player decisions
- **Input:** Takes choices from the player
- **Library:** `random` is used for random events

## 🗺️ Game Flow
Library → Laboratory → Garden → Cave → Treasure
